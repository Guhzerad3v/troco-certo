# 💰 Troco Certo

Site para controle de finanças pessoais, desenvolvido como projeto prático do semestre no curso de Análise e Desenvolvimento de Sistemas (ADS).

> 🚧 **Em desenvolvimento.** O código está sendo publicado aos poucos, em commits ao longo das próximas semanas. Esta documentação será atualizada junto.

## 📌 Visão geral

O Troco Certo tem como objetivo ajudar a pessoa a organizar o próprio dinheiro em um só lugar, de forma simples e visual.

## 💰 Troco Certo

Site para controle de finanças pessoais, desenvolvido como projeto prático do semestre no curso de Análise e Desenvolvimento de Sistemas (ADS).

> 🚧 **Em desenvolvimento.** O código está sendo publicado aos poucos, em commits ao longo das próximas semanas. Esta documentação será atualizada junto.

## 📌 Visão geral

O Troco Certo tem como objetivo ajudar a pessoa a organizar o próprio dinheiro em um só lugar, de forma simples e visual.

## 👥 Divisão do projeto

| Pasta       | O que tem                                 | Responsável |
|-------------|-------------------------------------------|-------------|
| `frontend/` | A página: HTML, CSS e JavaScript          | Pessoa 1    |
| `backend/`  | O servidor (API) em Node.js               | Pessoa 2    |
| `database/` | O banco de dados SQLite (arquivos `.sql`) | Pessoa 3    |

## ▶️ Como executar

Precisa do [Node.js](https://nodejs.org) versão 22.5 ou mais nova (confira com `node --version`).

```bash
# 1. Clone o repositório e entre na pasta
git clone [https://github.com/Guhzerad3v/troco-certo.git](https://github.com/Guhzerad3v/troco-certo.git)
cd troco-certo

# 2. Instale as dependências e inicie o servidor
cd backend
npm install
npm start
